# MeetMate market and store materials

This folder contains market positioning, Chrome Web Store listing copy, publication evidence, release-submission notes and synthetic marketing assets. These are **not** a declaration of current Chrome Web Store publication status.

- `.specs/`: store listing and positioning documents.
- `release-*`: historical release-submission / public-version checks; retain original timestamps and observed results.
- `scripts/`: synthetic screenshot/video demo fixture.
- `www/screenshots/4.5.9/` and `www/media/`: synthetic marketing screenshots and video; not runtime extension assets.

For current listing and review status, re-check the Chrome Web Store and authenticated publisher dashboard rather than relying on historical evidence.
