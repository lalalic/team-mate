## MANDATORY pre-flight (run before EVERY recording, no exceptions)

The recording pipeline assumes Chrome is already in a live, joined Teams
meeting with MeetMate's UI mounted. Without that, scenarios fire against
an empty page and produce useless clips. Always run:

```sh
cd /Users/lir/Workspace/free2/team-mate
python3 scripts/live-welcome.py --no-reload          # joins next calendar meeting
# or, if already in a meeting and you don't want to re-join:
python3 scripts/live-welcome.py --no-reload --no-join
```

Then verify all four UI elements are present (all must return `true`):

```sh
agent-browser eval 'JSON.stringify({rail:!!document.querySelector("#meetmate-rail"),duration:!!document.querySelector("[data-tid=\\"call-duration\\"]")})'
```

Only then call `run.sh` to record.

## MANDATORY post-flight (run after the LAST demo of a batch)

After all demos finish — or if the batch aborts — leave the Teams meeting
so it doesn't sit open consuming the user's mic/bandwidth:

```sh
agent-browser eval 'document.querySelector("button[data-tid=\\"hangup-main-btn\\"]")?.click()'
```

Leave-button selector `button[data-tid="hangup-main-btn"]` verified on
Teams v2 (2026-05-18). If Teams redesigns, re-probe:

```sh
agent-browser eval 'JSON.stringify(Array.from(document.querySelectorAll("button[data-tid]")).map(b=>b.getAttribute("data-tid")).filter(t=>t&&(t.includes("hangup")||t.includes("leave"))))'
```

## Surface

- **type**: Chrome MV3 extension
- **driver**: `agent-browser` (Playwright — manages its own browser context)
- **target_url**: `https://teams.microsoft.com/v2/` — must have an active
  meeting with live captions enabled
- **load**: build the extension first (`yarn --cwd team-mate build` or
  `npx webpack -c ./webpack.config.js --mode=production --devtool=false`),
  then load `team-mate/extension/` as unpacked in the user's running Chrome.
  The skill never spawns its own Chromium — it attaches to the user's profile.
- **panel root**: `#aichat` — the side panel injected by [src/content.js](src/content.js)

## Action recipes

Each line below is a literal storyboard DSL line. Drop into a step
verbatim.

### Trigger a scenario (the most common way to surface realistic content)

```
agent-browser eval document.body.setAttribute('data-replay','<scenario-name>')
```

Uses the `data-replay` DOM attribute (consumed by a MutationObserver in
the content script). DOM mutations cross JS-world boundaries; CustomEvent
dispatch and `postMessage` on `window` do not.

### Type a question into the Ask bar

```
agent-browser eval document.querySelector('.mm-r-asker input')?.focus()
agent-browser type ".mm-r-asker input" "Your question here"
agent-browser click .mm-r-send
```

### Click a rail log entry to expand details

```
agent-browser click .mm-r-log-entry.mm-r-kind-fact
```

### Spotlight the sidebar rail

```
spotlight #meetmate-rail
```

## Recording region *(optional)*

Default: full Chrome window (recommended — shows Teams + sidebar + center panel together).

To crop to just the sidebar rail:
```js
document.querySelector('#meetmate-rail').getBoundingClientRect()
```
